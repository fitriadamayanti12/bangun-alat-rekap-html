# Bangun Alat Rekap Sendiri

Latihan membangun **alat rekap stok gudang** dengan HTML + JavaScript yang berjalan **100% offline** di browser: data dari Excel disalin (Copy-Paste), diolah di komputer sendiri, dan tidak dikirim ke mana pun.

## Struktur

```
bangun-alat-rekap/
├── README.md
└── sesi-2/                    ← Input dari Excel dan angka kontrol
    ├── INSTRUKSI-LATIHAN.md   ← mulai dari sini
    ├── starter/rekap.html     ← titik awal (hasil akhir Sesi 1)
    ├── data/                  ← data dummy (xlsx dan tsv)
    └── hasil/                 ← tempat menyimpan pekerjaanmu
```

## Cara mulai

1. Baca `sesi-2/INSTRUKSI-LATIHAN.md`.
2. Salin `sesi-2/starter/rekap.html` ke `sesi-2/hasil/rekap.html`.
3. Kerjakan tugas berurutan; isi `sesi-2/hasil/catatan-sesi-2.md`.

## Penting

- Semua data di repositori ini **karangan**. Jangan mengunggah data asli perusahaan.
- Kode Sesi 2 diambil dari materi yang dibagikan mentor (`https://xgen-html-fmcg.vercel.app`), bukan dari repositori ini.
